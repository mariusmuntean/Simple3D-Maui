# Simple3D Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task by task. Track each task and commit each verified milestone.

**Goal:** Deliver a small portable 3D drawing library with a MAUI view and an interactive demo for iOS, Android and Mac Catalyst.

**Architecture:** Portable geometry and projection compile for plain net10.0. The MAUI layer maps projected triangles to GraphicsView and owns touch interaction. The demo consumes only the public library.

**Tech Stack:** C#/.NET 10, .NET MAUI GraphicsView, System.Numerics, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-26-simple3d-design.md`

## Global constraints

- MAUI targets: `net10.0-ios;net10.0-android;net10.0-maccatalyst`.
- Keep geometry independent of MAUI; avoid engine and test NuGet dependencies.
- Document painter rendering limitations and do not advertise heavy scenes as GPU accelerated.

## Review focus

- Empty or zero-sized viewport returns no triangles.
- Objects behind the camera are not projected.
- Invalid zoom and camera pitch cannot create NaN or an inverted camera.
- Geometry caching does not leak mutable mesh arrays to consumers.
- Far faces draw before near faces.
