    Read(TextReader)

    Reads triangles and strictly convex planar polygons; leaves the reader open. Supports v x y z [1], vt u [v [0]], vn x y z, and independent positive/negative face indices. Every face must use the same attribute layout. Named objects/groups, material references and smoothing directives are ignored. Source attribute counts, output vertices and triangles are limited to MaximumElements.
