    Class DepthRenderer

    Opaque software triangle rasterizer with per-pixel depth and picking. Instances reuse depth scratch storage and are not thread safe.

    Remarks

    Transforms use single precision; triangles whose transformed positions or normals overflow or collapse are skipped. There is no far clipping plane.
