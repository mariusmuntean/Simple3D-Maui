    ApplyExpressions(Shape, IReadOnlyDictionary<string, float>)

    Blends named expressions into every node of shape (at any depth) that uses a bound mesh, keeping the pose and transforms. Unknown names and nonfinite intensities are ignored.

    Declaration
    public Shape ApplyExpressions(Shape shape, IReadOnlyDictionary<string, float> intensities)
    Parameters
    Type Name Description
    Shape shape
    IReadOnlyDictionary<string, float> intensities
    Returns
    Type Description
    Shape
    Remarks

    The result shows exactly the supplied expressions: expressions left out return to neutral. Intensities clamp to [0,1]; binary expressions snap at 0.5. Contributions sum and clamp per target. Every mesh bound by any of the model's expressions gets new weights (replacing its mesh.weights defaults); other meshes keep theirs. Meshes absent from the shape are skipped.
