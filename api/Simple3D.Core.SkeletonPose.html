    Blend(SkeletonPose, SkeletonPose, float)

    Blends two poses of the same skeleton: each joint rotation is spherically interpolated and the root offset linearly, so amount 0 gives from and 1 gives to. Use it to crossfade animations or to ease toward a tracked pose.
