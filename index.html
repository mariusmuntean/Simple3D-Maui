    Small 3D scenes for .NET MAUI

    Simple3D draws opaque, depth-aware illustrations on iOS, Android, and Mac Catalyst. Build scenes from boxes, spheres, cylinders, pyramids, lines, arrows, or your own indexed mesh. Place a SceneView in a MAUI page, then drag to orbit, pinch to zoom, and tap to pick the visible shape.

    Start with Getting started, then learn scenes and cameras, meshes and groups, and interaction and picking. The showcases use the same fifteen scene factories as the interactive app. The API reference covers both library projects.

    Use the library under the MIT license. Source and the gallery app are in the repository.
